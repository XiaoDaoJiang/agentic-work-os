# Return Context Questions

Ask after a natural return or an explicitly marked `research_scheduled` recovery walkthrough. Record time, help, and actual evidence opened.

1. What was the objective / DoD?
2. What is the current execution state or where did it stop?
3. What changed in the code/workspace?
4. What was the VerificationInvocation and result?
5. What Review/Accept/Reject decision exists, if any?
6. What should happen next?

For each answer record: correct / partial / incorrect / unknown, evidence opened, facilitator help, and whether an external terminal was required.
